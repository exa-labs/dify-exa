# Privacy Policy

## Data Collection

This plugin sends user-provided queries and parameters to the Exa API (https://api.exa.ai) on behalf of the user. No data is stored by the plugin itself.

## Third-Party Services

This plugin communicates with the Exa API. Please refer to Exa's privacy policy at https://exa.ai/privacy-policy for details on how Exa handles your data.

## Credentials

Your Exa API key is stored securely within the Dify platform and is only used to authenticate requests to the Exa API. It is never logged or transmitted to any other service.
